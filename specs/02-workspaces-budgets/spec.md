# SPEC 02 — Workspaces, Budgets & Categories

## WHAT
- Creación y administración de Presupuestos (Workspaces).
- Dashboard inicial de presupuestos.
- Sistema de categorías y grupos de categorías.
- Asignación de reglas y objetivos a categorías.

## WHY
- El presupuesto es el núcleo del sistema Zero-Based Budgeting.
- Proveer una estructura para clasificar el dinero y darle un "trabajo".

## HOW
- Base de datos relacional para `budgets`, `category_groups`, `categories`.
- Interfaz Action-First: mostrar indicadores clave de estado primero.
