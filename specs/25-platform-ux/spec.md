# SPEC 25 — Platform UX

## WHAT
- Comportamientos transversales ("Shell" y "Action-First UX").
- Search unificado, Command Palette (Ctrl+K).
- Centro de notificaciones.

## WHY
- Transforma una herramienta contable aburrida en un "sistema operativo".
- Mejora la eficiencia (navegación por atajos) y retiene a power users.

## HOW
- Componentes globales en el Layout principal.
- API unificada para búsqueda global sobre `payees`, `transactions`, `categories`.
